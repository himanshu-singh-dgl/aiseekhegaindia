# AISeekhegaIndia

Community-driven platform for Machine Learning, Deep Learning, and Language Models.

This directory contains the Next.js + Fumadocs frontend.

## Develop

```bash
npm install
npm run dev
```

The frontend runs on [http://localhost:3000](http://localhost:3000). Set
`NEXT_PUBLIC_API_URL=http://localhost:4000` to connect it to the Express API.

## Build

```bash
npm run build
```

## Content

- Docs: `content/docs/`
- Blog: `content/blog/`
- Static assets: `public/`

## Scripts

| Command | Action |
|---------|--------|
| `npm run dev` | Start the frontend |
| `npm run build` | Build the frontend |
| `npm run typecheck` | Type-check the frontend |
