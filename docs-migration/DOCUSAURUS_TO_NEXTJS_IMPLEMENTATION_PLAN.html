7. Phased implementation (trackable)

Phase 0 — Discovery P0 2–4 h

Status: Not started

Tasks

  • Read docusaurus.config.ts, sidebars.ts, package.json
  • Inventory all /docs/* URLs from sidebar IDs
  • List assets under docs/** and static/
  • Classify each doc: interactive (MDX) vs static (HTML candidate)
  • Write inventory section in MIGRATION_REPORT.md

Deliverables

  • URL inventory table · HTML vs MDX classification · asset list

Exit criteria

  • Every sidebar doc ID mapped to target /docs/... URL

Phase 1 — Next.js scaffold P0 1 day

Status: Not started

Tasks

  • Init Next.js 15 App Router + TypeScript on branch migrate/next-pure
  • Add Tailwind v4, path alias @/
  • Create folder skeleton (Section 6.3)
  • Add scripts: dev, build, start, lint, typecheck
  • Placeholder app/page.tsx and app/docs/[[...slug]]/page.tsx
  • Keep Docusaurus deps until Phase 8

Deliverables

  • next.config.ts · app/layout.tsx · empty component/config folders

Exit criteria

  • npm run dev and npm run build succeed

Phase 2 — Content port P0 1.5–2 days

Status: Not started

Tasks

  • Move docs/** → content/docs/** (keep slugs)
  • Port static/img → public/img
  • Create config/docs-sidebar.ts from sidebars.ts
  • Preserve co-located PNG paths
  • Port frontmatter with minimal change
  • Initial pass: keep as MDX; HTML conversion in Phase 10

Deliverables

  • content/docs/** · config/docs-sidebar.ts · public/img/**

Exit criteria

  • All content files in place; sidebar config matches Docusaurus order

Phase 3 — Docs subsystem P0 1.5–2 days

Status: Not started

Tasks

  • Implement lib/content/load-doc.ts (MDX first; HTML stub for P1)
  • Build DocsLayout — sidebar from docs-sidebar.ts
  • TOC from heading extraction · breadcrumbs · prev/next nav
  • Wire @next/mdx + remark/rehype plugins
  • Prose styles via styles/docs.css + typography plugin
  • Map routes to /docs/<section>/<slug>

Deliverables

  • DocsLayout.tsx · load-doc.ts · app/docs/[[...slug]]/page.tsx

Exit criteria

  • All 38 sidebar docs render at correct URLs; images load

Phase 4 — Site chrome P0 1–1.5 days

Status: Not started

Tasks

  • Create config/navigation.ts from docusaurus.config.ts
  • Build SiteHeader (Resources, Topics, Fellowship, Tutorials, GitHub, Contribute)
  • Build SiteFooter (Docs, Community, More columns)
  • Port homepage, fellowship, contribute pages
  • Migrate Infima/CSS-module styles to Tailwind

Deliverables

  • SiteHeader.tsx · SiteFooter.tsx · marketing pages under app/

Exit criteria

  • Nav/footer links resolve; marketing pages match prior IA

Phase 5 — Interactive islands P0 1–1.5 days

Tasks

  • Port LogisticRegression/** → components/features/logistic-regression/
  • Port CurriculumTree → components/features/curriculum-tree/

  • Register in lib/mdx-components.tsx
  • Preserve external links (e.g. eda.aiseekhegaindia.com)

  • Working tutorial + curriculum tree in production build

Exit criteria

  • Canvas/input/navigation functional on both interactive docs

Phase 6 — Blog P0 2–4 h

Status: Not started

Tasks

  • Port welcome post to content/blog/
  • Build app/blog/page.tsx index + [slug]/page.tsx
  • Preserve slug 2024-04-24-welcome (or Docusaurus-equivalent URL)

Phase 7 — Link hardening P0 4–8 h

Status: Not started

Tasks

Exit criteria

  • Light/dark/system work on docs + marketing pages

Phase 12 — CI + production checklist P1 4–6 h
