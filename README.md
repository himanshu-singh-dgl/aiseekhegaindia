# AISeekhegaIndia

Monorepo for the AISeekhegaIndia platform.

## Structure

| Folder | Description |
|--------|-------------|
| `frontend/` | Next.js app (docs, blog, marketing pages) |
| `backend/` | API server (Node.js) |

## Quick start

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
```
