2. Pros & cons

Why move — and what you give up.

Pros Move to Next.js

  • Full control over homepage, fellowship, interactive demos
  • App Router, RSC, better DX for app-like features
  • Easier path to auth, analytics, CMS, APIs later
  • Tailwind already partially present
  • Cleaner long-term stack if this becomes more than docs
  • Broader hiring / ecosystem than Docusaurus plugins

Cons Migration cost

  • Lose built-in docs chrome unless using Fumadocs/Nextra
  • Rewrite @site / @theme / @docusaurus imports
  • SEO risk if URLs/metadata change without redirects
  • Own search, sitemap, OG, broken-link checks
  • Contributors learn new local commands
  • Astro leftovers add cleanup work

Stay if…

Primary goal is content publishing, team is small, and custom React stays light. Upgrade Docusaurus and remove Astro leftovers instead.

Move if…

You want a product-quality marketing + learning platform, interactive tutorials will grow, or you need Next features (API, auth, edge, CMS).

3. Architecture options

Pick one stack before implementation starts.

Recommended

A · Next + Fumadocs

Fit: High

  • Docs UX close to Docusaurus
  • MDX + Tailwind native
  • Full Next flexibility
  • Learn one docs layer

B · Next + Nextra

Fit: Good

  • Mature docs-on-Next
  • Solid for content sites
  • Less flexible theming in some setups

C · Bare Next + MDX

Fit: Only if highly custom

  • Maximum control
  • Build sidebar/TOC/search yourself
  • Highest effort

D · Stay Docusaurus

Fit: Lowest cost

  • Keep docs features free
  • Clean Astro leftovers
  • Limited app growth
